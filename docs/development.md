# 開発手順

Node.js 22 LTS（22.12以降）を使用します。コマンドはリポジトリ直下で実行してください。

| コマンド | 用途 |
| --- | --- |
| `npm ci` | 依存関係のインストール |
| `npm run dev` | 開発サーバーの起動（3000番ポート） |
| `npm run check` | 公開範囲、lint、型、テストの検証 |
| `npm run build` | 本番用ビルド |
| `npm start` | ビルド済みアプリの起動 |

CIではプルリクエストとmainへの更新時に、インストール、検証、ビルドを実行します。権限は読み取り専用です。デプロイやGoogle APIへの定期アクセスは行いません。

## Vercel

Next.jsを選択し、Root Directoryを`apps/web`に設定します。ルートのロックファイルを参照できるよう、アプリのルート外にあるファイルへのアクセスを有効にしてください。正規URLは`https://siegemaps.com`です。

ドメインとDNSの設定は別途必要です。`VERCEL_ENV=preview`では検索エンジンの登録対象から外します。原図の照合や呼称のレビューが未完了の階層もnoindexとします。

## 公開しないファイル

`private-docs/`とルートの`maps/`はGitの管理対象外です。アプリから参照しません。サイトで使う画像は`apps/web/public/maps/`に含めてコミットしてください。認証情報やDMを公開ファイルにコピーしないでください。

カメラ、マイク、位置情報は使用しません。レスポンスのPermissions-Policyでも無効にしています。

## 文書とコメント

ドキュメントは日本語で記述します。コードコメントは原則不要です。コードやGit履歴だけでは分からない制約や理由を補足する場合に限り、英語のコメントも使用できます。
