# 文面と配色

## 文面

画面を見れば分かる操作説明や、機能を言い換えただけの文章は置きません。見出し、操作名、エラー、データが空の場合の状態表示を簡潔に書きます。開発中・プレビュー・近日公開といった表示は使いません。

方針の参考：[GOV.UKのUI文面ガイド](https://www.gov.uk/service-manual/design/writing-for-user-interfaces)、[MicrosoftのUIテキスト指針](https://learn.microsoft.com/en-us/windows/win32/uxguide/text-ui)。

文面は`apps/web/content/ja.json`に集約します。日本語を変更する場合は、掲載場面と意味を確認してください。

場所の名前の総称には「マップ名称」を使い、文脈が明らかな箇所では「名称」とします。部屋だけでなく、階段や細かなポジションの名前も対象です。味方に敵の位置などを伝える行為は「報告」と呼び、名称をまとめたサイト自体の呼び名とは区別します。

用例：[さく8氏の「マップ名称を覚える2つのコツ」](https://www.youtube.com/watch?v=ulWkb0r3hWE)、[ΣISAKA氏の競技シーンについての投稿](https://note.com/sigmaisaka/n/n935bf98c2117)、[gosso_siege氏の「報告の取捨選択」](https://gosso-siege.hatenablog.com/entry/2019/04/05/202430)。これらは実際の用例であり、現在の利用頻度を統計的に示すものではありません。

## 配色

白、黒、緑を基調とし、薄いミント色を補助色に使います。緑は`#00BA83`、本文は`#111B16`、リンクは`#006C4B`です。

Plus Ultraの参考画像から配色の方向性だけを取り入れています。ロゴやその一部、原画像は使用しません。公式提携や公認を示す表現も避けます。

マップ上の文字の読みやすさ、キーボード操作、スマートフォンでの表示を優先します。
