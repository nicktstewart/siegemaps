# 競技マッププールと収録状況

確認日：2026-10-28 JST。

サイトの収録マップ数と、その時点の競技マッププールは別です。背景を収録したマップは11種類で、競技9マップを含みます。名称とゲーム内照合の完了を意味しません。

[Ubisoftの2026-10-15更新記事](https://news.ubisoft.com/en-us/article/1yzD1EJhuk6vXsTt8eP1hf/rainbow-six-siege-operation-split-fire-midseason-update-legend-division-arrives-noor-buffs-and-a-final-ranked-map-rotation)の「Pro Maps」を基準にします。

競技マップは9/9マップの背景を収録しています。収録済みのConsulateとSkyscraperは、この競技プールには含まれません。既存ページがあることと、競技対象であることを混同しないでください。「収録済み」は、背景や名称の全てが現行ゲーム内で確認済みという意味ではありません。

## 採用する版

- **Fortress**：[Operation Tenfold Pursuit](https://www.ubisoft.com/en-us/game/rainbow-six/siege/news-updates/seasons/tenfoldpursuit)のフルリワーク。2025-12-02のシーズン開始時に競技プールへ入り、Skyscraperに代わりました。廊下、爆弾エリア、侵入口などが変わり、中庭は屋外になっています。
- **Villa**：[Operation Split Fireの開始記事](https://news.ubisoft.com/es-mx/article/54Tp1XyVksGff3eqvjEG03/play-rainbow-six-siege-operation-split-fire-today)で2026-09-01に公開された対象部分の更新。構造のリワークは地下のみです。1階Living Room / Libraryの爆弾エリアが地下へ移りました。上階の背景は既存図を使用します。3月のビジュアル更新と9月の構造更新を区別してください。

## 既存資料の扱い

原図集のVilla地下とFortressは、更新後の図としては採用していません。Villaの2階・1階は既存図を採用しています。Villaの地下図には旧ガレージ側の開いた構造が残り、Fortressの図にも旧構造が残っています。ファイルの保存日時やフォルダ名だけで、ゲーム内の版を判断しないでください。

Ubisoftの[Villaページ](https://www.ubisoft.com/en-us/game/rainbow-six/siege/game-info/maps/villa)と[Fortressページ](https://www.ubisoft.com/en-us/game/rainbow-six/siege/game-info/maps/fortress)から取得できるZIPも調査しました。配布図には旧図と共通する構造があり、最新ページに置かれているだけでは更新後の図とは確認できません。Fortressページの「Map reworked: December 2025」という記載も、リンク先ZIPの内容が更新済みである証明にはなりません。

[R6CallsのVilla図](https://www.r6calls.com/img/maps/villa.svg)と[Fortress図](https://www.r6calls.com/img/maps/fortress.svg)は比較用の候補です。現行ゲームとの全階層照合は未完了で、サイトの背景としては採用していません。

## 追加したコミュニティ図

[StratbookのVilla](https://www.stratbook.gg/maps/villa)（Y11S3）と[Fortress](https://www.stratbook.gg/maps/fortress)（Y10S4）のSVGを基に、地下1枚とFortressの2枚を白黒へ調整しました。編集可能なSVG、JPEG、配信用WebPを収録しています。出典は[マップデータ](content.md)に記録しています。

新規5階層は`layoutStatus: unverified`です。壁、開口部、階段、ハッチ、地下爆弾エリア・中庭の屋外判定の全てを現行ゲーム内で確認したわけではありません。日本語名称は空で、英語名称はR6Callsを参考に採用背景へ手動配置した草案です。現行ゲーム内での確認は未完了です。

別の制作例として、[FPS Tactician作者によるFortressリワーク図の投稿](https://www.reddit.com/r/Rainbow6/comments/1p6p05d/fortress_reworked_and_lair_blueprints/)も確認しました。今回の背景の出典はStratbookであり、この作者の図を使用したものではありません。
