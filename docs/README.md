# Public documentation

SiegeMaps is a free Japanese callout reference for Rainbow Six Siege. The initial frontend supports map/floor URLs, a responsive map canvas and configurable labels. It does not yet contain a reviewed callout dictionary.

- [Architecture](architecture.md): repository boundaries, content model and future services.
- [Development](development.md): local commands, checks and deployment setup.
- [Content](content.md): backgrounds, callout format and contribution workflow.

Thank you to Sternab for creating and sharing the free-use [original map blueprints](https://drive.google.com/drive/folders/1nBG6OcSTvI3fCErspyEPWwVwxRiLRj3C).

All documentation in this directory is public. Personal correspondence and internal planning are excluded from the repository.
