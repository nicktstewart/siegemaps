# 名称エディタ

地図上で名称を直接編集し、各階層のJSONファイルに保存するツールです。自分のパソコンだけで動き、公開サイトには含まれません。プログラミングの知識は不要です。

## はじめに一度だけ

1. [Node.js](https://nodejs.org/ja/download)のLTS版をインストールします。
2. [GitHub Desktop](https://desktop.github.com/)をインストールし、このリポジトリをクローンします。

## 開き方

リポジトリのフォルダを開き、次のファイルをダブルクリックします。

- Windows：`名称エディタ-Windows.cmd`
- Mac：`名称エディタ-Mac.command`

黒いウィンドウが開き、準備ができるとブラウザに名称エディタが表示されます。初回は準備に数分かかります。使い終わったら黒いウィンドウを閉じてください。

Windowsで「WindowsによってPCが保護されました」と表示された場合は、「詳細情報」→「実行」を選びます。Macで開けない場合は、ファイルを右クリックして「開く」を選びます。

コマンドで開く場合は、リポジトリ直下で`npm run editor`を実行します。

## 使い方

| 操作 | 方法 |
| --- | --- |
| マップ・階を選ぶ | 右上のマップ選択と階のボタン |
| 名称を選ぶ | 地図上の名称、または右の一覧をクリック |
| 位置を動かす | 地図上の名称をドラッグ |
| 名称を直す | 右の欄を書き換え。先頭の名称が地図に表示されます。↑↓で順番を変更 |
| 略称 | 「略称」欄に追加。サイトでは「略称を表示」を選んだときだけ表示されます |
| 新しく追加 | 「名称を追加」を押し、地図上の場所をクリック |
| 削除 | 名称を選び、「この名称を削除」 |
| 英語の名称 | 「編集する名称」で「英語」を選択。英語の名称には出典URLが必要です |
| 確認状況 | 現行のゲームで確認した名称は「確認済み」にします |
| 元に戻す・保存 | 「元に戻す」（Ctrl+Z）、「保存」（Ctrl+S） |

地図は、マウスホイールまたは＋・−で拡大縮小し、名称以外の部分をドラッグして移動できます。保存しないまま別の階へ移動しようとすると確認が表示されます。

## 変更を送る

保存した内容は、パソコン内の`apps/web/content/maps/<マップ>/<階>.json`に書き込まれます。GitHub Desktopを開くと変更したファイルが表示されるので、内容を確認して要約を書き、「Commit to main」を押します。その後、「Push origin」またはプルリクエストで送ってください。送信の権限がない場合は管理者に連絡してください。

## 仕組み

`scripts/editor.mjs`が必要なパッケージを準備し、開発サーバーを`127.0.0.1`だけで起動してブラウザを開きます。編集画面は`/editor`、保存は`/api/editor`です。どちらも開発サーバーでのみ動作し、本番ビルドでは404を返します。保存時に、サイトと同じ形式の検査を通らない内容は書き込みません。
