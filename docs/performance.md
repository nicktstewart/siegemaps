# 配信と軽量化

利用者の大半が日本国内にいることを想定しています。全ページを静的生成し、VercelのCDNから配信します。現状はリクエスト時のサーバー処理がないため、Functionsの実行リージョンを東京に指定しても、画像やHTMLの配信経路は変わりません。

## マップ画像

選択済みのJPEG原本を`assets/map-sources/`、配信用のWebPを`apps/web/public/maps/`に保存し、両方をGitで管理します。原本は公開ディレクトリの外に置き、ブラウザには配信しません。クローン後は追加のダウンロードや画像生成なしで起動できます。

アジトは編集用SVGも同じフォルダに保持しています。配信画像の生成元はJPEGです。SVGを修正した場合は、4800×3600のJPEGへ書き出してから、以下の画像生成コマンドを実行してください。

- 詳細画面：幅3200px、WebP品質85。
- 一覧用サムネイル：幅768px、WebP品質80。
- 縦横比と向きを維持し、余白の切り抜きは行いません。名称の相対座標は変わりません。
- ファイル名に内容のSHA-256の先頭12桁を含めます。WebPだけに1年間のimmutableキャッシュを設定し、HTMLには適用しません。
- 変換済みの画像を直接配信し、Next.jsのリクエスト時画像変換は使いません。

原本を更新したら、リポジトリ直下で実行します。

```sh
npm run images:optimize
npm run check
npm run build
```

生成スクリプトは名称や出典を維持したまま、画像と階層JSONの寸法・パスを更新します。不要になった旧ハッシュのWebPは削除します。原本、生成画像、JSONをまとめてコミットしてください。`images:check`は原本からの再生成結果と配信画像・JSONが一致することを検証し、CIでも実行します。

転送量の上限をテストで検証します。詳細用は1枚200KB未満、サムネイルは20KB未満です。構造の細かい画像を追加する場合は、拡大時の読みやすさを確認してから上限を見直してください。

## 追加リクエストの削減

一覧で先読みする画像は先頭の1枚だけにし、残りは遅延読み込みします。一覧から各マップへのリンクは自動プリフェッチを無効にし、選択前に各マップのページや操作用JavaScriptを取得しないようにします。

日本語は端末のシステムフォントを使用します。英字ロゴ用のBarlow Condensedは必要なLatin・700のフォントだけを同梱し、Google Fontsへの外部リクエストをなくします。

## CDNと費用

CloudflareはDNS only、配信はVercelに統一します。[VercelのCDN](https://vercel.com/docs/caching/cdn-cache)は利用者に近い拠点から配信します。国内からの実測なしに特定の応答時間は保証しません。

[Flat Rate CDN](https://vercel.com/blog/introducing-flat-rate-cdn)は費用の予測に役立ちますが、無制限の固定料金ではありません。継続的な利用増加で次の請求期間から上位枠に移る場合があります。CDN枠はチーム内の対象プロジェクトで共有されます。画像変換などの他の利用料金まで定額になるわけではありません。

本サイトでは画像を事前変換するため、[Vercelの画像最適化処理とそのキャッシュの利用料金](https://vercel.com/docs/image-optimization/managing-image-optimization-costs)を避けます。通常のCDNリクエストとデータ転送は発生するため、VercelのUsageで両方を確認してください。
